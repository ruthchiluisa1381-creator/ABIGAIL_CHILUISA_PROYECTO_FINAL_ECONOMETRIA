## 🛠️ Estructura del Repositorio

El proyecto se compone de las siguientes carpetas y archivos clave:

* `data/`: Datos crudos y procesados de la ENEMDU.
* `src/`: Scripts de Python para procesamiento (`limpiar_datos.py`) y generación de resultados (`generar_resultados.py`).
* `outputs/`: Tablas (.csv, .tex), gráficos (.png) y resultados analíticos (.txt, .json).
* `dashboard/`: Aplicación en Next.js/React desplegada en Vercel.
* `paper/`: Código fuente en LaTeX (`main.tex`, `referencias.bib`) y PDF compilado final (`CARRANZA_MATIAS_PROYECTO_FINAL_ECONOMETRIA.pdf`).
